# Beyond Brute Force
Project for the module of _Information Retrieval_ the course of _Multimedia Information Retrieval and Computer Vision_ of the Master Degree of Artificial Intelligence and Data Engineering, University of Pisa.

The project consists in a single Colab notebook with all necessary matierial inside.
Due to file size limits, the notebook cannot be visualized directly on the browser.
Due to compatibility issues, some sections of the cell outputs may not be visualized correctly on your local machine after the notebook download.

Therefore, we recommend opening the notebook directly on Colab at the following link: [Colab Notebook](https://drive.google.com/file/d/1dA2xXKgSJKxs37atHtPDQoKhE3dwt3zk/view?usp=sharing).
